账号命名决策
先试水的账号名，要一听就记住
参考华与华符号逻辑：借已有文化原型，短、顺口、能做视觉锤、有延展性。先试水不等于不考虑长远，名字要能扛3年。
命名底层逻辑：不能太"机构"（太重），不能太"个人"（太轻），最好是一个有文化感的动作词或状态词——用户一听就知道这是跟身体/生活有关的，但又不像普通养生号。
归身
首推
两个字，有动作感和方向感——从外面回到自己的身体。和紫尘阁"把人带回身体"完全一致。视觉锤好做：一个回归的圆弧。可延伸：归身课堂、归身社、归身节令。
⚠ 需查重商标，若已有人注册则换备选
安身
首推
"安身立命"是中国人骨子里的熟词，不需要解释。两个字，稳、顺口。视觉锤：安住在中心的一枚圆。可延伸：安身书院、安身社、先安身再安神。
⚠ 若做商标需查类别（健康/教育类）
养着
备选A
最口语，最有互联网内容味。"先别折腾，养着"——反常识、接地气，适合小红书冷启动。缺点是长期品牌感不如归身/安身。
更适合做栏目名，不做总账号名
三衡生活
备选B
直接点出体系，有辨识度。缺点是"三衡"需要教育，冷启动成本高。适合公众号/知乎用，不适合小红书冷启动。
适合做后期品牌升级后的正式账号名
节令人
创意备选
借"节令"（节气/节律）造一个新词。"节令人"=懂节律的人，有一种生活方式认同感。独特，但需要更多解释。
风险：需要教育成本，冷启动慢
自医堂
创意备选
"自医"=让自己成为自己的医生，和三衡"教会一万人不生病"高度一致。"堂"字有空间感。缺点：容易触碰医疗合规红线。
⚠ 合规风险较高，需谨慎评估
最终建议：小红书+知乎先用 「归身」 或 「安身」 试水（二选一，先查商标）。公众号用「紫尘阁书院」保持正式感。3个月后跑出数据，再决定是否全平台统一。两个名字都符合华与华的"文化原型借力"逻辑，短、顺、有画面，长期扛得住。
第一阶段 · 第1-30天
你一个人把内容模型跑通
这个月义工不动，你先动。目标：让内容机器转起来，找出哪些题最打人，为第2个月招团队打好样板。
📍 本月核心任务：找到你的"爆款母题"你一人
Week 1-2注册3个账号（小红书/知乎/公众号），用AI每天产出内容，手改发布。只发A类反常识题，测哪种开头最有人停。
Week 2-3根据数据找出Top 3爆款母题结构，建立你自己的"选题模板库"。这是给未来团队成员复制的样本。
Week 3-4开始在内容里轻轻埋"书院/义诊"钩子，测试从内容到公众号的转化路径，确认哪个平台的用户质量更高。
全月建立Gemini Gem + NotebookLM知识库。这个月你是在给AI"喂食"，让它越来越懂紫尘阁的语气和世界观。
🎯 月底验证指标：小红书涨粉>300，知乎有3篇500+赞的回答，公众号新增关注>100，找到2-3个稳定打人的选题结构。

第二阶段 · 第31-60天
招募3人小组，激活公众号/视觉义工
你已经有了样板内容和数据。现在招团队，同时开始给义工"预热"，让他们知道你在做什么，为第3个月做准备。
👥 本月核心任务：搭出3人小组 + 预热义工1+3人
团队第1人：内容执行会用AI、能写文案、认同三衡。从义工里找——公众号组65人是首选。用样板内容做"上岗测试"，不靠简历靠实操。
团队第2人：视觉+发布做图、做封面、管账号发布、处理评论数据。视觉传播组30人是首选，他们已经做过紫尘阁视觉工作。
团队第3人：社群+义工对接管微信群、管义工联系、管线下活动对接。书院线下义工57人中找——要找在杭州、活跃、有时间的人。
义工预热在义工群发一条话：「我们要做一件大事，需要你们一起——不是现在，是3个月后，先看我们做什么。」让他们先当第一批读者/分享者。
🎯 月底验证指标：3人小组形成SOP，每天AI出稿→内容执行改发→数据复盘的流程跑通。小红书粉丝>1000，公众号关注>500，百家号+头条号开始分发改写内容。
如何从义工里找团队成员

不要发招聘启事，要直接找人。

步骤一
列出候选人名单
从公众号组（65人）+ 视觉传播组（30人）里，找出参与年数≥2年、活跃度高的人，约20个候选人。
步骤二
一对一私聊，说实话
「我在做一件你早就认同的事，需要一个靠谱的人，你愿意听吗？」不画大饼，先聊需求和时间，再谈。
步骤三
实操测试，不靠面试
给候选人一个真实选题，让他用Gemini出稿，自己改。看改出来的东西像不像紫尘阁的语气。这个测试1小时内出结果。

第三阶段 · 第61-90天
发动义工，全国城市节点落地
你已经有了内容模型+3人团队。现在发动义工，从"看我做"变成"跟我做"。城市节点从杭州、郑州、上海先跑。
🚀 本月核心任务：义工变传播节点1+3+义工网络
发动方式不是"帮我转发"，而是"成为城市联络人"——给义工一个身份，不只是让他们干活。
内容义工招募面向全国义工发起"紫尘阁内容共创计划"：每月输出1篇自己城市的体感内容，紫尘阁帮你改稿发布，署你的名字。
城市节点落地杭州/郑州/上海各找1个义工联络人，每月组织1次线下体感分享，用紫尘阁统一模板，数据回传汇总。
GEO内容爆发义工贡献内容+AI改写+多平台发布，单月可产出200+篇覆盖不同城市、不同关键词的内容，让AI搜索引擎开始收录。
🎯 月底验证指标：全平台内容总量突破300篇，至少3个城市有线下活动记录，在百度/知乎/小红书能搜到"三衡""安身""揉腹+杭州"等关键词。义工内容贡献者≥20人。
义工内容共创：怎么做才符合人性
❌ 错误做法
发通知说「请义工们帮忙转发内容」→没人理，因为没有身份感，只有任务感。
✅ 正确做法
给义工一个「紫尘阁城市内容官」身份，统一物料，让他分享的是"自己的故事"，紫尘阁给背书。
💡 核心原则
人性：人只会为"让自己更好看"的事持续付出。你给的不是任务，是让义工在朋友圈显得有内容、有品位、有使命感。
GEO战略 · AI搜索引擎优化
3个月内让各大AI都能搜到紫尘阁
GEO（Generative Engine Optimization）不是SEO，AI引用内容的逻辑不同。要让ChatGPT/Claude/Gemini回答"中医养生/道家生活"时出现你，需要做三件事：权威性、覆盖面、结构化。
①
建立权威锚点
知乎：深度解释型文章，被AI引用概率最高
公众号：建立品牌词"三衡理论"的搜索锚定
百家号：百度系AI（文心）优先爬取
头条号：字节系AI优先爬取
②
关键词矩阵覆盖
核心词：三衡理论、道家养生、揉腹
长尾词：睡不实怎么办、肚子紧是什么原因
城市词：杭州养生、杭州中医书院
人名词：赵无尘、紫尘阁
③
内容量级要求
3个月目标：300篇+覆盖不同关键词
知乎：50篇深度回答
小红书：90条图文
公众号：30篇长文
百家/头条：130篇分发改写
让AI引用你的内容格式
结构化表达
每篇内容要有明确的"问题-解释-结论"结构，AI更容易提取和引用。不要写散文，要写"可被切片"的内容。
品牌词重复出现
每篇内容里至少出现一次"三衡理论"或"紫尘阁"，让AI学会这个词和这个品牌的关联。
跨平台同步
同一个核心观点在5个平台都有版本，AI抓取时会发现多个来源说同一件事，可信度大幅提升。
义工如何帮助GEO
内容共创
每个义工写1篇"我在XX城市实践三衡理论的体感记录"，不同城市、不同关键词，规模化覆盖。
互动引流
义工在知乎/小红书的相关问题下留评论、点赞、收藏，提升内容权重和被AI收录的概率。
转发扩散
义工把内容转发到自己的朋友圈/群，带动自然流量，这些流量数据会被平台算法认为是高质量内容。
义工激励体系
给义工什么，他们才会持续动？
义工不是员工，用钱驱动不长久。真正让人持续付出的是：身份感、成长感、被看见、和这件事有关联的利益。
核心原则：让义工觉得"我是这件事的一部分，不只是帮别人做事"。他们传播的是自己的认同，不是你的广告。
义工层级画像核心驱动力给他们的你的成本
内容官
城市内容创作者		 有内容能力，在本地有影响力，认同三衡 被看见、有署名、有品牌背书 紫尘阁官方账号转载+署名｜「城市内容官」证书｜课程学习优惠｜优先参加线下密训 极低（内容资产+信任背书）
联络人
城市节点组织者		 在本地能组局、有朋友圈，希望做点有意义的事 身份感、组织感、被信任 「紫尘阁城市联络人」正式身份｜城市活动物料支持｜每季度与阁主/主理人视频连线1次｜书院体验名额 低（身份+连接+少量物料）
传播官
内容分享者		 普通义工，没有内容能力，但愿意转发分享 归属感、参与感、顺手 每周2条现成内容（直接转发）｜分享积分累积换课程/书院体验｜「我是紫尘阁第XXX位传播官」身份牌 极低（内容已生产，给分享模板）
核心团队
3人小组		 从义工中选出，能力强，认同深 成长、收入、参与品牌建设 薪资/分成｜优先晋升「城市合伙人」｜直接参与品牌决策 正常人力成本，但获得的是认同度最高的人
发动义工的话术（不要画大饼）
「XX，我在做一件事，你早就认同的事，只是现在开始在互联网上说出来。

我需要你做的很简单：每周看我们发的内容，如果觉得好，就转发到你的朋友圈，不用加任何说明。

三个月后，等我们跑通了，再邀请你真正参与进来。那时候你已经是最早知道这件事的人。」

——不是任务，是邀请你见证。
义工积分制（简单版）
转发1条内容到朋友圈 = 1分
带自己体感的分享 = 3分
写一篇体感文章被采用 = 10分
组织1次本地分享会 = 30分
100分 = 书院体验1次 / 课程优惠券1张
关键：积分不要做复杂系统，用一个共享文档就够。简单，才有人参与。
