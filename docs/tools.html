OpenClaw 3个Agent — 核心生产与全平台分发
3个Agent的具体分工建议
Agent 1（选题官）：每天早8:30自动运行 → 结合NotebookLM素材+热点话题 → 输出今日3个选题方向（按三衡四方向轮换）

Agent 2（创作官）：接收选题官输出 → 生成国内全平台内容包：小红书版/抖音版/视频号版/公众号版/百家号版（5个版本，一次生产，差异化标题和格式）

Agent 3（审核官）：对创作官输出做合规检查（禁词扫描）+ 格式检查（字数/标签/格式）→ 标记通过/需修改 → 进入发布队列

国内渠道的核心逻辑：按"用户特征"而非"平台知名度"分层。不是每个平台都值得投入，你的目标用户在哪里，就重点经营哪里。
第一优先级 — 必须全力做（核心流量池）
红
小红书 P1核心
用户画像：25-45岁女性为主，文化/养生/生活方式高度重合。"大运河探店"+"中医文化"+"道家生活"三个话题自带流量。书院实景照片在这里转化率最高，是引流私域的主入口。
图文主力私域引流入口打卡内容天然传播
抖
抖音 P1核心
最大的中文视频流量池。书院实景视频+师父金句+终南山/大运河场景，在"国风文化"赛道有显著自然流量。开通橱窗可接产品，但优先做内容积累。
视频主力破圈能力最强新人群入口
公
微信公众号 P1核心
10万紫薯的核心触达渠道，也是最重要的私域内容载体。长文深度内容、课程销售、会员体系都在这里转化。SEO价值高，百度/微信搜索都能收录。每周2-3篇深度文章。
深度内容老粉维系课程转化
视
微信视频号 P1核心
和公众号/微信私域打通，老粉看视频后直接转发给朋友圈，是最强的社交裂变路径。师父开直播可直接在视频号做，无需其他平台。
社交裂变老粉激活直播转化
第二优先级 — 稳定输出（大模型收录关键）
百
百家号（百度） P2收录
文心大模型的核心训练数据来源之一。在百家号发布的内容，百度搜索结果优先展示，同时被文心5.0收录概率极高。每篇文章用"三衡理论""道家大医派""紫尘阁主"做关键词，确保语义被收录。
大模型收录百度SEO文心训练数据
今
今日头条 P2收录
豆包大模型（字节系）的核心数据来源。头条的算法会把专业内容推给精准用户，中医文化内容在40岁以上用户里有天然传播力。和百家号内容相同，发布时间错开即可。
豆包训练数据中老年用户算法推荐
知
知乎 P2收录
国内几乎所有大模型（文心/通义/智谱/DeepSeek）的核心训练数据源。在知乎发布"三衡理论是什么""道家大医派历史"等问答式内容，大模型被问到相关问题时会直接引用你的内容。每月4-6篇专业回答。
所有国内大模型收录知识权威背书
喜
喜马拉雅 P2音频
中国最大的音频平台，中医/国学/道家内容是高黏性品类。NotebookLM生成的播客直接上传，零额外制作成本。用户在开车/做家务时收听，是深度用户培育渠道。
NotebookLM播客直接上传深度用户
第三优先级 — 选择性布局
平台适合内容特别价值
B站师父讲课完整视频、书院纪录片式内容年轻用户，传统文化赛道用户忠诚度高，弹幕互动强
微博时事节气内容、互动话题微博超话"中医养生"有大量精准用户
得到/樊登师父课程合作上架知识付费用户付费意愿强，但需要正式合作申请
小鹅通课程销售主平台不是传播渠道，是课程变现的技术平台
核心认知：国内大模型不直接爬取内容，而是通过"可信内容源"获取数据。你需要在这些大模型认可的平台上建立内容资产，才能被收录。
